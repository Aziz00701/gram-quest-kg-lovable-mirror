# Salmanova Grammar Quest mirror

This folder is a local mirror of the public Lovable deployment:

https://gram-quest-kg.lovable.app/

It contains the downloaded HTML, CSS, and JavaScript assets for the visible app routes.

## Run locally

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Then open:

http://127.0.0.1:4173/
